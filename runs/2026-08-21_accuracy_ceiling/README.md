# 정확도 천장 측정 (2026-08-21)

목표 정확도를 어디에 걸지 정하기 위해, **압축을 아예 하지 않은 설정**
(균일 8비트 · 프루닝 없음)의 정확도를 QAT 학습 데이터 크기별로 잰 기록.

| `AUTOCIM_QAT_TRAIN_SIZE` | 1,024 | 4,096 | 8,192 | 16,384 |
|---|---|---|---|---|
| 정확도 | 0.822 | 0.907 | 0.910 | **0.893** |
| 소요 | 25초 | 65초 | 118초 | 228초 |

4,096 → 8,192는 +0.003뿐이고 **16,384에서는 오히려 떨어진다.** 데이터를 늘려
천장을 올리는 레버가 4,096 근처에서 이미 소진돼 있고, 그 위로는 학습
노이즈(±0.015 수준)가 더 크다. 이 측정이 없었다면 `target_accuracy`를
천장 위(0.91~0.95)에 걸어 3시간을 버렸을 것이다.

본 실행 기록은 `../2026-08-22_neurosim_0p88/`.

재현: `sh run_ceiling.sh` (`ceiling_probe.py`를 학습 크기별로 호출, 원본 출력은 `ceiling_results.txt`).
